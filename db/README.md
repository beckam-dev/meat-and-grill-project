# Base de Datos en Postgresql

## Scripts
-	Para poder usar los scripts, primero se debe crear una base de datos en pgadmin.
-	Los siguientes scripts se deben ejecutar en orden de menor a mayor para evitar errores.

| N° | Nombre 					| Descripción 						 			| Status 	  |
|----|--------------------------|-----------------------------------------------|-------------|
| 1. | 01_create_tables.sql 	| Define las tablas y sus relaciones 			| En progreso |
| 2. | 02_insert_data.sql 		| Datos iniciales de prueba 		 			| Pendiente   |
| 3. | 03_create_procedures.sql | Procedimientos iniciales de prueba 			| Pendiente   |
| 4. | init_db.sql 				| Ejecuta todos los scripts anteriores en orden | Pendiente   |
	
## Convenciones

-	Nombre de tablas y columnas en inglés.
-	Nombre de tablas en plural.
-	Nombres en SQL en formato snake_case.
-	Documentación y comentarios en español.
